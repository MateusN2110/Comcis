GOOGLE DRIVE

The public Client ID is saved locally. Access tokens are held only in memory, never saved or sent to our servers. Google requires this site's HTTPS origin to be authorized. The read-only permission can view every Drive file and may require verification beyond personal testing.

Google Cloud credentials ↗

Only authorize a copy of Comics hosted on a website you control. Disconnecting revokes the token. Review Google account access.

LARGE COMICS

CBZ/ZIP archives up to 3 GiB use partial reads. RAR/CBR archives use a separate WebAssembly decoder (up to 128 MiB) and require memory to unpack; larger CBR files should be converted to CBZ. Only the current page and nearby pages are decompressed (48 MB maximum per page). Comics from Google Drive use HTTP byte-range streaming and require an active connection; local files over 100 MB must be selected again after the app restarts. Your phone must still be able to decode each image, so performance cannot be guaranteed for every file on iPhone 7.
